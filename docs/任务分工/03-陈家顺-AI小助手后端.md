# 陈家顺：AI 小助手后端任务单

## 任务目标

在 Spring Boot 后端增加 DeepSeek 服务端代理，提供稳定的 `/ai/chat` 接口。API Key 必须只存在于服务器环境变量中，前端和代码仓库均不可见。

## Windows 11 环境

安装 Git for Windows、64 位 Eclipse Temurin JDK 8、IntelliJ IDEA Community（或 VS Code Java 扩展包）、Postman/Apifox。项目自带 Maven Wrapper，无需另装 Maven。

从项目总负责人孙木文处单独获取测试 Key，并只在当前 PowerShell 会话设置：

```powershell
$env:DEEPSEEK_API_KEY="负责人提供的测试密钥"
$env:DEEPSEEK_BASE_URL="https://api.deepseek.com"
$env:DEEPSEEK_MODEL="deepseek-v4-flash"
cd backend
.\mvnw.cmd spring-boot:run
```

不得把真实值写入任何 `.properties`、`.java` 或文档。

## 共享文件处理

不要直接提交对 `application-dev.properties`、`application-prod.properties`、`pom.xml` 的改动。把所需配置键写进 `application-ai.example.properties`，由赵友为合并。优先使用 `spring-boot-starter-web` 已提供的 `RestTemplateBuilder`，避免无必要增加 SDK 依赖。

## 具体实现要求

1. 实现 `POST /ai/chat`，接收 `messages` 数组，只允许 `user`、`assistant` 两种前端角色；后端自行插入固定 system 提示词。
2. 校验消息数量 1～20、每条内容 1～2000 字、总字符数上限；拒绝空消息和未知字段造成的异常。
3. 服务端请求 `POST ${DEEPSEEK_BASE_URL}/chat/completions`，模型从 `DEEPSEEK_MODEL` 读取，默认 `deepseek-v4-flash`。以 [DeepSeek 官方 Chat Completion 文档](https://api-docs.deepseek.com/api/create-chat-completion) 为准。
4. system 提示词定位为甘露支教学习助手，要求使用适合儿童和教师的表达，并提醒不要处理学生姓名、电话、住址等敏感信息。
5. 只向前端返回最终答案，不透传 `reasoning_content`、供应商响应头或 Key。
6. 设置连接超时和读取超时；将供应商 401/429/5xx 分别转换为本站可理解的 502、429、503/504 响应。不要把供应商完整响应直接抛给用户。
7. 日志只记 requestId、耗时、状态和匿名化用户 ID；不得记录 Key 和完整对话正文。
8. 缺少 Key 时应用可以启动，但调用 AI 接口返回明确的“AI 服务未配置”，不能在启动阶段让整个网站崩溃。
9. V1 只要求非流式接口。流式 SSE 仅作为加分项，并且不得影响非流式测试。
10. 接口调用受赵友为提供的 Token 认证保护，管理员、团队账号、学生账号均可使用；未登录返回 401。另加简单的单用户频率限制或预留明确扩展点，避免 Key 被刷。

## 测试要求

测试不得调用真实 DeepSeek，也不得消耗真实额度。使用 `MockRestServiceServer` 或可替换的 HTTP 客户端模拟：

- 正常回答。
- 空消息、超长消息、超过 20 条。
- 未登录。
- 缺少 API Key。
- DeepSeek 401、429、500、超时。
- 上游返回空 choices 或缺少 content。
- 日志与响应中不出现测试 Key。

## 验收标准

- Postman 使用合法 Token 能得到统一的 `{code,message,content}` 响应。
- 浏览器网络请求中看不到 DeepSeek Key，前端只访问本站 `/ai/chat`。
- 切换 `DEEPSEEK_MODEL` 环境变量无需重新编译。
- 上游不可用时不影响新闻、课件、留言等其他接口。
- `.\mvnw.cmd test` 通过。

## 交付边界

本任务不建会话数据库、不保存聊天记录、不负责前端页面。把配置键、接口示例、错误码和测试结果写入 `docs/integration/ai-backend.md`，交给乔轩轲和赵友为。
