安装 Git for Windows、VS Code、Node.js `22.12+`、64 位 Eclipse Temurin JDK 8、IntelliJ IDEA Community、MySQL Server 8.0、MySQL Workbench、Postman/Apifox，以及 64 位 LibreOffice。LibreOffice 用于把 PPT/PPTX 转成 PDF 预览文件。

## 表单和数据要求

上传必须使用弹窗，字段依次为：标题、JPG/PNG 封面、上传者（从当前登录的管理员或团队账号自动取得，只读）、课程类型、具体科目、年份、文件。

- 通识课程：具体科目从管理员维护的列表选择，初始为语文、数学、历史、生物、英语。
- 特色课程：具体科目由上传者填写，限制 2～30 字。
- 管理员维护的通识科目最多 12 个，支持新增、改名、停用；有课件引用的科目不得物理删除。
- 年份默认当前年，只允许当前年向前 9 年。
- 允许 PDF、PPT、PPTX、JPG、JPEG、PNG、WebP，单文件最大 200MB；移除当前 DOC、DOCX、MP4 接受项。

数据库补丁增加/调整：上传者用户 ID、年份、自定义科目、原文件路径、预览文件路径、文件类型、大小、状态和必要索引。不要把上传者只存成可伪造字符串。

## 预览与权限要求

1. PDF 使用同源资源地址预览；图片用 `<img>`；PPT/PPTX 上传成功后由 `soffice --headless --convert-to pdf` 生成预览 PDF。
2. 转换失败不能丢原文件，数据库记录预览失败状态并提示可下载；进程要有超时、唯一工作目录和错误日志。
3. 游客可浏览课件元数据，但下载必须登录；团队和学生均可下载。
4. level=0 管理员和 level=1 团队账号均可上传、删除和管理课件记录；level=2 学生账号不可上传、删除或管理。课件管理权限不限制为本人上传的记录。
5. 搜索按标题、科目、上传团队进行模糊匹配；所有参数化 SQL 禁止字符串拼接。
6. 删除课件时由当前有权操作的管理员或团队账号二次确认，同时清理原文件、预览和封面；任一文件不存在时也要安全处理。

## 验收标准

- 管理员和团队账号都可在弹窗完成 PDF、PPTX、PNG 各一次上传；学生和游客不能上传。
- PPTX 能在网页中看到转换后的 PDF；视频和 DOC 文件在前后端都被拒绝。
- 游客点下载被要求登录；团队/学生可下载原文件；管理员和团队账号可删除、管理课件，学生账号和游客不可删除。
- 科目第 13 个新增请求被拒绝；最近 10 年过滤和关键词搜索准确。
- 50MB 以上文件显示进度，失败可重试，分片合并后 MD5/大小正确。
- 管理端对 level=0/1 显示课件管理和删除入口，对 level=2 隐藏并由后端返回 403。
- `npm run build`、`.\mvnw.cmd test` 通过。
