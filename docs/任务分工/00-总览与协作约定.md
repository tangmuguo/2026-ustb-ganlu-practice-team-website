# 甘露网站第二阶段任务总览与协作约定

## 1. 本轮范围

当前项目技术栈为 Vue 3 + Vite 7 + Element Plus + Tailwind CSS，后端为 Spring Boot 2.4.4 + MyBatis + MySQL 8。

本轮只完成 PDF 明确要求的功能：网站整体、团队风采、课件共享、注册登录、互动留言、AI 小助手，以及已有新闻/轮播功能的集成。PDF 第 7 页明确降级的“智能匹配系统”不做。

孙木文担任本项目总负责人，统一总览全局工作，对初始项目创建、文件共享、项目范围、任务优先级、阶段进度、每日 Pull Request 审核、跨模块协作、风险处理和最终交付负责。

## 3. 统一业务口径

1. 用户权限继续沿用现有 `user.level`：`0=系统管理员`、`1=甘露团队账号`、`2=学生账号`。
2. 下表是账号权限的最高优先级口径；其他说明、页面显示和后端鉴权如与此表冲突，一律以此表为准。

| 功能 | 系统管理员 `level=0` | 甘露团队 `level=1` | 学生账号 `level=2` |
|---|:---:|:---:|:---:|
| 浏览首页、课件、团队风采、新闻、轮播图、留言 | ✅ | ✅ | ✅ |
| 登录 | ✅ | ✅ | ✅ |
| 注册学生账号 | ✅ 公开接口 | ✅ 公开接口 | ✅ 公开接口 |
| 轮播图管理 | ✅ | ❌ | ❌ |
| 新闻管理 | ✅ | ❌ | ❌ |
| 团队账号管理 | ✅ | ❌ | ❌ |
| 学生账号管理 | ✅ | ✅ | ❌ |
| 上传课件 | ✅ | ✅ | ❌ |
| 删除、管理课件 | ✅ | ✅ | ❌ |
| 上传队员、支教照片 | ✅ | ✅ 仅自己的团队 | ❌ |
| 删除队员、支教照片 | ✅ 可删除任意团队内容 | ✅ 仅自己的团队 | ❌ |
| 上传团队日志、荣誉 | ✅ | ✅ 仅自己的团队 | ❌ |
| 删除团队日志、荣誉 | ✅ 可删除任意团队内容 | ✅ 仅自己的团队 | ❌ |
| 发布留言 | ✅ | ✅ | ✅ |
| 回复留言 | ✅ | ✅ | ✅ |
| 删除留言和回复 | ✅ | ✅ | ❌ |

3. 留言列表对游客开放；`level=0/1/2` 均可发布和回复；`level=0/1` 可删除留言和回复，`level=2` 不可删除。
4. 团队风采必须以 `teamId`、`pageId` 建立关联，不能继续把前端路由中的团队 ID 当作 `userId` 查询。流程固定为“年份列表 → 当年小队列表 → 小队详情”。
5. 管理员可上传、删除任意团队的队员照片、支教照片、日志和荣誉；团队账号只能上传、删除自己绑定团队的上述内容；学生账号无上传和删除权限。团队提交的风采内容先进入待审核状态，管理员发布后才出现在公开页面。
6. 课件分两层：`courseType=1 通识课程`、`courseType=2 特色课程`。通识课程从管理员维护的科目中选择，初始科目为语文、数学、历史、生物、英语，科目总数不得超过 12；特色课程允许填写自定义科目。
7. 课件增加 `year`，公开页面默认只展示当前年份向前 9 年的数据。支持关键词、科目、年份筛选。
8. 课件只接收 PDF、PPT/PPTX 和 JPG/PNG/WebP 图片。PDF、图片直接预览；PPT/PPTX 在服务端转换为 PDF 后预览；原文件供有权限用户下载。`level=0/1` 均可上传、删除和管理课件，`level=2` 不可进行这些操作；通识科目分类仍由管理员维护。
9. DeepSeek 密钥只能放在后端环境变量中，不能写入 Vue 文件、`.env.*` 或提交到仓库。后端默认模型使用可配置的 `deepseek-v4-flash`；不要新写即将停用的旧模型名。接口格式以 [DeepSeek 官方 Chat Completion 文档](https://api-docs.deepseek.com/api/create-chat-completion) 为准。
10. 所有新接口统一返回：`{ "code": 200, "message": "...", "content": ... }`。失败使用合适 HTTP 状态码，并在响应中给出稳定的业务提示。
11. 登录后的身份以服务端校验的 Bearer Token 为准。留言、团队内容和课件接口不得再相信请求体中的 `userId` 或 `author`。

## 4. Windows 11 统一基础环境

全员安装 Git for Windows、VS Code、Chrome 或 Edge。前端成员安装 Node.js `22.12+`（团队统一同一大版本，推荐 24 LTS）以及 VS Code 的 “Vue - Official” 扩展；Vite 7.0.0 的项目要求为 `^20.19.0 || >=22.12.0`。

后端成员安装 64 位 Eclipse Temurin JDK 8、 VS Code Java 扩展包(`Extension Pack for Java`) 、MySQL Server 8.0 和 Postman/Apifox。项目自带 Maven Wrapper 3.9.10，不要求单独安装 Maven。

基础检查命令：

```powershell
git --version
node -v
npm -v
java -version
mysql --version
```

首次启动：

```powershell
cd frontend
npm ci
npm run dev

cd ..\backend
.\mvnw.cmd spring-boot:run
```

数据库由 MySQL Workbench 导入根目录 `ganlu.sql`，再按负责人提供的 `database/patches/*.sql` 顺序执行。任何人不得把真实数据库密码提交到仓库。

## 6. 前后端公共接口约定

### 登录身份

- 前端请求头：`Authorization: Bearer <token>`。
- 后端从 Token 获取当前用户，不接收前端伪造的用户 ID。
- 公开接口：主页、团队风采公开内容、课件元数据列表、新闻、轮播图、留言列表和学生账号注册。
- `level=0/1/2`：发布留言、回复留言，以及其他明确要求登录的公共功能。
- `level=0/1`：学生账号管理、课件上传与管理、留言和回复删除。
- `level=1`：只能上传、删除自己绑定团队的队员照片、支教照片、日志和荣誉。
- `level=0`：轮播图管理、新闻管理、团队账号管理、团队创建、内容审核、课件分类维护，以及任意团队内容的上传和删除。

### AI 小助手 V1

`POST /ai/chat`

```json
{
  "messages": [
    { "role": "user", "content": "如何设计一节小学科学课？" }
  ]
}
```

成功响应：

```json
{
  "code": 200,
  "message": "success",
  "content": {
    "answer": "...",
    "requestId": "..."
  }
}
```

V1 先保证非流式接口稳定；流式输出属于加分项，必须在 V1 验收后再做。
